# Egatari examples / Egatari の見本

Examples of [Egatari](https://github.com/egatari/egatari-spec) lessons, each one a pair: **the request you give a chat AI** and **the lesson it produced**, made with [Egatari Studio](https://github.com/egatari/egatari-studio) and the [components library](https://github.com/egatari/components).

Egatari の見本集。1 つの見本は「チャットの AI に渡す頼み方の文」と「それでできた教材」の組です。

Status: being set up (2026-10-24). Layout, metadata and the first series are planned in the Egatari standards work.
準備中（2026-10-24）。並べ方・見本の情報・最初のシリーズは計画中です。
