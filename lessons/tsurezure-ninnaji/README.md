# 『徒然草』仁和寺にある法師

高校 1 年の言語文化の見本。本文と説明のスライドは縦書きにそろえ、横書きでしか置けない図（法師の道のり）と表（「けり」の意味）の 2 枚だけを横にしてまとめた。

## 本文

『徒然草』第五十二段（兼好法師、鎌倉時代末。著作権の保護期間外）。通行の本文に従う。
