(sec-rmmjsu)=
## 本文の窓とスライドを行き来する

Egatari ファイルには、スライドと台本のほかに**本**を入れられる。本は、スライドで話したことを、読む文章として書いたものだ。スライドは話の順に見せ、本はあとで読み返したり、自分のペースで読んだりするのに向く。

本のあるファイルを開くと、スライドの横か下に本文が出る。本文の節は、スライドのステップとつながっている。

- 本だけの表示では、節の頭の **スライドで見る** を押すと、その節に当たるスライドへ飛ぶ
- 本文の中のリンク（「スライド「平均と中央値」のステップ 1」のような青い字）を押すと、そのスライドとステップへ飛ぶ
- スライドの側では、ツールバーと一緒に **本で読む** が出る。押すと、スライドと本を並べた表示になり、本文のその節が開く。本文の左上の ←（戻る）で、スライドだけの表示に戻る（スマートフォンのような狭い画面では、本だけの表示で開く）
- スライドと本を並べている間は、スライドを進めるにつれて、本文もその所まで動く。本文を途中まで読んでいるときは、読んでいる所を動かさない

スライドで図の動きを見て、本文で説明を読み直す、という使い方ができる。印刷した本では、スライドへのリンクが「→ スライド 5・ステップ 3」と刷られる。

(sec-qw25xh)=
## 配置（スライド・スライドと本文）

本のあるファイルは、3 つの並べ方で見られる。Studio では **プレビュー ▾** の **表示** で選ぶ。学習者が見る画面と同じ並べ方になる。

- **スライド：** スライドだけを見せる。発表や、声を聞きながら見るときに
- **スライドと本：** スライドと本文を並べる。図と説明を一緒に追いたいときに
- **本：** 本文だけを読む。読み返しや予習に

プレーヤーの中で並べ方を変えても、同じように切り替わる。

(sec-mjjtcd)=
## 本を作るには（Studio が本を作れるバージョンで足す）

v0.6.19 の Studio も、本を読む・少し直す・印刷することはできるが、本を新しく作ることはまだできない。本を書くのは、今は Claude Code などのコマンドの道具だ（付録）。

本のあるファイルを Studio で開いたときにできることは次のとおりだ。

- ツールの列の **本** で「本」のパネルを開き、本文を直して **保存** する
- スライドを直した後に、本文と合っていないかもしれない所を一覧で見て、読み比べて **確認済みにする**
- **ファイル ▾ → エクスポート ▸ → 本を印刷** で、A4 縦に印刷する

Studio で本を作れるようになったら、この節に作り方を足す。
